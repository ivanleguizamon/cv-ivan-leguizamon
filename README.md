# CV online - Iván Gustavo Leguizamón

Sitio estático listo para publicar. Abrí `index.html` para una vista local.

## Publicarlo gratis con GitHub Pages

1. Creá una cuenta en GitHub y un repositorio público llamado `cv-ivan-leguizamon`.
2. Subí **todos** los archivos de esta carpeta al repositorio.
3. En el repositorio, entrá a **Settings > Pages**; en "Build and deployment" elegí **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guardá. GitHub mostrará un enlace parecido a `https://tu-usuario.github.io/cv-ivan-leguizamon/`.

El sitio ya incluye teléfono y correo para contacto directo.
